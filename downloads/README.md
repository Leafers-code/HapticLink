# HapticLink downloads

## 1.5 preview — current

Adds the searchable community plugin browser: 69 projects including 44 game integrations, live list refresh, offline cache, platform filters and one-click connection-tab setup. FFXIV has its Dalamud repository and in-game instructions. Host/port-only clients can be assigned to a game tab. External game mods still require their own installation; community game sessions are not live-tested. [Plugin guide](../src/linux/PLUGINS.md).

- [Windows x64 app](HapticLink-win-x64-1.5.0-preview.7z) — extract with 7-Zip and run HapticLink.exe. [Windows guide](../src/linux/README-Windows.md).
- [Linux x64 app](HapticLink-linux-x64-1.5.0-preview.tar.xz) — self-contained; extract and run ./HapticLink. [Linux guide](../src/linux/README-Linux.md).
- [Source code](HapticLink-source-1.5.0-preview.zip)
- [SHA-256 checksums](SHA256SUMS-1.5.0.txt)

Keeps the compact classic UI, frequency-range capture, events, transparent overlay and focus pause. Per-application audio isolation remains Linux-only. Native Linux hardware/compositor behavior requires desktop testing. See [validation](../src/linux/VALIDATION.md).
