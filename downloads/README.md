# HapticLink downloads

## 1.3 preview — current

Adds the Plugins manager: controls and status for 12 built-in features, plus installable CS2, Intiface/Buttplug and HTTP-event profiles. Profiles support event mapping edits, import/export, catalog updates, enable/disable, removal and undo. [Plugin guide](../src/linux/PLUGINS.md).

- [Windows x64 app](HapticLink-win-x64-1.3.0-preview.7z) — extract with 7-Zip and run HapticLink.exe. [Windows guide](../src/linux/README-Windows.md).
- [Linux x64 app](HapticLink-linux-x64-1.3.0-preview.tar.xz) — self-contained; extract and run ./HapticLink. [Linux guide](../src/linux/README-Linux.md).
- [Source code](HapticLink-source-1.3.0-preview.zip)
- [SHA-256 checksums](SHA256SUMS-1.3.0.txt)

Keeps the compact classic UI, frequency-range capture, events, transparent overlay and focus pause. Per-application audio isolation remains Linux-only. Native Linux hardware/compositor behavior requires desktop testing. See [validation](../src/linux/VALIDATION.md).
