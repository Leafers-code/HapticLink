# HapticLink downloads

## 1.4 preview — current

Adds preconfigured CS2 and Overwatch 2 game tabs, with EQ integrated into Audio. CS2 has event effects and a config installer. Overwatch uses the separate OverStim companion, with connection configuration and launch controls. Plugins manages game tabs, imports, removal and undo. [Plugin guide](../src/linux/PLUGINS.md).

- [Windows x64 app](HapticLink-win-x64-1.4.0-preview.7z) — extract with 7-Zip and run HapticLink.exe. [Windows guide](../src/linux/README-Windows.md).
- [Linux x64 app](HapticLink-linux-x64-1.4.0-preview.tar.xz) — self-contained; extract and run ./HapticLink. [Linux guide](../src/linux/README-Linux.md).
- [Source code](HapticLink-source-1.4.0-preview.zip)
- [SHA-256 checksums](SHA256SUMS-1.4.0.txt)

Keeps the compact classic UI, frequency-range capture, events, transparent overlay and focus pause. Per-application audio isolation remains Linux-only. Native Linux hardware/compositor behavior requires desktop testing. See [validation](../src/linux/VALIDATION.md).
