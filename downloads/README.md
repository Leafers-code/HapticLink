# HapticLink downloads

## 1.2.1 preview — current

Restores the original compact dark interface: connection/output cards, top-bar arm and panic, always-visible source meters, inline sliders and the bottom log. Events and overlay are retained. EQ now selects Bass/Mids/Treble or an exact custom capture frequency range, with draggable cutoffs.

- [Windows x64 app](HapticLink-win-x64-1.2.1-preview.7z) — extract with 7-Zip and run HapticLink.exe. [Windows guide](../src/linux/README-Windows.md).
- [Linux x64 app](HapticLink-linux-x64-1.2.1-preview.tar.xz) — self-contained; extract and run ./HapticLink. [Linux guide](../src/linux/README-Linux.md).
- [Source code](HapticLink-source-1.2.1-preview.zip) — shared app and original Windows source.
- [SHA-256 checksums](SHA256SUMS-1.2.1.txt)

Includes the Intiface-compatible event receiver, CS2 events, game-focus pausing, transparent overlay and frequency-selective haptics EQ. Windows uses WASAPI output capture and ViGEm/XInput; application-stream isolation is Linux-only. See the [integration guide](../src/linux/INTEGRATIONS.md) and [validation](../src/linux/VALIDATION.md). Native Linux hardware/compositor behavior still requires desktop testing.
