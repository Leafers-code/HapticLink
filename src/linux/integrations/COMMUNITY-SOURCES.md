# Community catalog sources

The bundled `community-catalog.json` contains factual project names, links, groups and platform/connection requirements from the [Renpona community index](https://github.com/Renpona/awesome-intiface-sfw-list/blob/sfw-list/README.md), retrieved November 3, 2026. Descriptions in the bundled snapshot are reduced to requirements; the upstream README is not bundled. Refresh reads that same fixed source at the user's request.

Discovery entries do not establish current compatibility. Project owners supply the external mods/apps and installation guides. FFXIV Vibe Plugin's repository URL and setup steps were checked against its [official README](https://github.com/kaciexx/FFXIV_Vibe_Plugin#installation). No external game-mod implementation or binary is included.
